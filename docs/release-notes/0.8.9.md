Strata 0.8.9 adds more ways to organize folders and fixes stale sizes and dates for files that change while you browse.

## New

- **Group files by kind.** Choose View ▸ Group By ▸ Kind in List, Icons, or Columns. Each local folder remembers its grouping, and files keep their sort order within each group.
- **Fit columns to filenames.** Turn on “Automatically fit columns to filenames” in View Options, or double-click a divider to fit just that column.
- **Reorder the Places sidebar.** Drag a section heading or use its Move Section Up and Move Section Down commands. Your order carries across windows.
- **See which cloud account you’re browsing.** The path bar starts with the account name and icon for iCloud Drive, Dropbox, OneDrive, and other synced folders. The account stays visible in narrow panes.

## Fixed

- **Watch downloads and exports grow.** File sizes and modification dates update as files change, including in deeper columns.
- **Keep expanded folders up to date.** When another app renames a file or folder, List view shows the new name and keeps your other files selected.
- **Drop files into the intended column.** Dropping on the first column’s background uses that folder even when a deeper column has keyboard focus.
- **Read tag controls in light and dark mode.** Buttons in Settings ▸ Tags have clearer contrast, including the favorite star and reorder arrows.
