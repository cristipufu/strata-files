Strata 0.8.8 adds tag management and folder tinting, improves Markdown previews, and fixes scrolling.

## New

- **Manage Finder tags.** Create and rename tags inline, choose colors, and organize sidebar tags and favorites in Settings ▸ Tags.
- **Tint folders by tag color.** Turn folder tinting on or off in Settings ▸ Tags. Custom folder icons are preserved.
- **Read Markdown with GitHub-style formatting.** Enjoy clearer headings, lists, quotes, tables and code blocks, with Mermaid diagrams rendered in the page.
- **Eject drives from the sidebar.** Use the eject button beside an external drive. Open panes leave the drive before ejection; failed attempts can be retried.
- **Open selected files together.** Files sharing a default app are opened in one request, so apps such as Preview can display them together.

## Fixed

- **Markdown appears immediately.** No more scrolling to reveal the contents, disappearing table sections, or stretched code backgrounds.
- **Reach the last item in Columns.** Horizontal scrollbars no longer cover the bottom of the file list.
- **Tag dots line up.** Larger dots align at the trailing edge of the Name column, making tagged files easier to scan.
