Strata 0.8.3 fixes a crash when switching SQLite tables and adds stability safeguards for file browsing, search, S3 transfers and archive caches.

## Fixed

- **Switch SQLite tables without crashing.** Switching between tables with different numbers of columns now clears the previous selection safely. The shared table preview also protects CSV and Excel previews when their columns change.
- **Additional safeguards during browsing and search.** Icons and Gallery safely ignore outdated item requests during updates. Folder suggestions, the command palette and Dock search also handle temporary native row changes safely.
- **More resilient S3 transfers.** Native XML parsing failures and incomplete service errors are handled without escaping into the app. Uploads and folder creation check response-size limits as replies arrive, and cancelling an upload leaves other requests on the same connection running. Discarded connections release their network sessions.
- **Bounded archive-cache metadata reads.** Cached archive origins are checked before reading and use a small, bounded read. Oversized metadata, links and nonregular files are refused.
