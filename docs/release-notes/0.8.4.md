Strata 0.8.4 makes Favorites and Frequent easier to manage, adds control over extensions in the Name column, and fixes View Options sizing and file-list updates during renaming.

## New

- **Drag sidebar folders into Favorites.** Drag a folder from Frequent or Locations between your favorites to pin it exactly where you want it.
- **Remove folders from Frequent.** Right-click a Frequent folder to clear its visit history. It can return as you visit it again.
- **Choose whether extensions appear in the Name column.** In View Options (⌘J), turn off “Show extensions in Name column” for a separate name-and-extension layout alongside the Extension column. The option starts enabled and applies to List views across windows.

## Fixed

- **View Options opens with room for its controls.** Fixed a sizing issue that could shrink the window to a tiny title bar with no visible settings.
- **File lists stay current when switching views during a rename.** Folder updates that arrive while editing are applied when you switch views, while abandoned updates are discarded. Cancelled editors also release their file state when the text field disappears.
- **Customize Toolbar has a matching menu icon.** The command in the View menu now has a wrench icon alongside the other commands.
