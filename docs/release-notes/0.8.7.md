Strata 0.8.7 adds custom themes and indexing controls, improves file selection and text sizing, and fixes crashes.

## New

- **Custom color themes.** Load your own palettes from `~/Library/Application Support/Strata/Themes/`.
- **Exclude folders from indexing.** Choose folders in Settings ▸ Search & Index to reduce memory use and search clutter.
- **Turn indexing off.** Control background indexing from Settings ▸ Search & Index.
- **Hidden Files toolbar button.** Add it using View ▸ Customize Toolbar.
- **File names up to 20 pt.** Adjust text in Settings ▸ Appearance, or use ⌘+ / ⌘− in List and Columns.

## Fixed

- **Less background CPU.** Catch up after installs, builds and bulk file changes with fewer full rescans.
- **Keep automatic reads local.** Indexing skips cloud-only folders and mounted volumes; background size estimates avoid downloads.
- **Folder sizes finish updating.** Inspector sizes now arrive in every view, including deeper Columns.
- **Drag to select between files.** In List and Icons, drags outside file icons and names draw a selection.
- **Sidebar sizing follows macOS.** Text and symbols respect System Settings ▸ Appearance ▸ Sidebar icon size.
- **F5/F6 use the open folder.** Copy and move into the folder shown in the other pane’s Columns view.
- **Prevent drag and Git badge crashes.** Fix the reported macOS 27 crashes when starting drags or drawing Git badges.
- **Git badges stay visible.** Fix badges disappearing after repeated redraws.

The file index is rebuilt once on the first launch after this update.
