Strata 0.8.0 adds sandboxed archive handling, OneNote previews and richer Markdown previews, with new customization options, clearer storage measurements, and fixes to search results, memory use and file-operation safety.

## New

- **Sandboxed archive handling.** Archive browsing, previews and extraction now parse archives in isolated, sandboxed helper processes. Strata validates extracted paths, links and file records before writing each item.
- **OneNote previews.** Preview `.one` sections with page navigation, formatted text, tables and pictures. Notebook contents show section order and colors from `.onetoc2` files.
- **Open Windows `.cab` archives and OneNote notebook packages.** Browse `.cab` and `.onepkg` contents, preview individual files and extract them directly in Strata.
- **Larger files inside archive previews.** Stream individual files up to 256 MB out of Space archive previews for opening or copying.
- **Mermaid diagrams, better tables and Find in Markdown.** Mermaid diagrams render offline. Table columns fit their content, and Find highlights text matches, with Return and Shift-Return moving between them.
- **Alternating row colors.** Enable zebra striping for List and Columns through Appearance settings or View Options.
- **Choose another terminal app.** Select a custom terminal in Settings. Open in Terminal, SSH, container-shell and project commands follow that preference.
- **Get Info in context menus.** Right-click a file or folder to open its selection in the Inspector.
- **More optional toolbar buttons.** Add Reload, Copy To, Move To, Sync and Connect through Customize Toolbar. These buttons are available to add; the default toolbar is unchanged.
- **Clearer storage measurements.** The Inspector distinguishes Size on disk from Logical size. Local Disk Usage charts show allocated space for visible items and identify incomplete measurements. The footer shows physically free space, with a tooltip distinguishing it from availability that includes reclaimable storage.

## Fixed

- **Better search results.** Exact folder-path matches rank ahead of partial matches. Command-palette results avoid duplicate files and folders, preserve explicitly chosen results by their identity, and start new searches at the top. Dock search also keeps selection and scrolling consistent.
- **Lower temporary memory use.** Duplicate scanning and streaming reads used by hashing, encrypted storage and SFTP uploads release temporary buffers as they go. Duplicate scans respond to cancellation while hashing large files.
- **Less redundant background work.** Index updates avoid repeatedly scanning the same folders. Duplicate, Compare, semantic-indexing and container-event progress updates are coalesced before reaching the interface.
- **Markdown preview stability.** Fixed a crash when rendering tables inside blockquotes.
- **More reliable HTML previews.** Pages already displaying stay in Preview while their images and styles finish loading, and larger photos can render within the preview's image limits.
- **Sidebar selection and home names.** Selecting a location also listed in Frequent keeps the occurrence you chose. Home displays its actual folder name.
- **Safer Undo across disks.** Undo and Redo recheck original file identities before queued moves act on them, including retries, so replacement items are left alone.
- **Safer server and container exports.** Missing files and folder-listing failures are reported instead of treating an unverifiable copy as complete.
- **Clearer protected-item refusals.** Trash checks protected system items and read-only volumes before starting a batch, with a specific explanation rather than a generic permissions error.
- **Safer Empty Trash.** Unreadable items are reported, and incomplete folder listings are not treated as complete before deleting their contents.
- **More reliable Ask Strata renaming.** Case-only rename conflicts recover under a visible name and explain where the item was left. Date-based renames consistently skip files missing the requested date, regardless of token capitalization.
- **SFTP disconnects.** Fixed a crash when a session disconnects during a request write. Queued writes refuse a closed session, and active writes keep their handle until they finish.
- **Trash sounds follow macOS settings.** Moving items to Trash and emptying it respect the system's interface-sound setting.

**Upgrading:** Strata rebuilds its search index once after upgrading. Operation History from earlier versions is not carried forward; new operations are recorded normally. Existing files remain unchanged.
