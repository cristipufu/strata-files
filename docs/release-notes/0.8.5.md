Strata 0.8.5 adds per-folder view settings, multi-view search and duplicate results, settings search in the Command Palette, OpenDocument spreadsheet and 3MF previews, offline LaTeX equations in Markdown, video storyboards and audio waveforms, and significantly reduces background indexing CPU usage.

## New

- **Per-folder view settings in View Options (⌘J).** Save a custom view mode, sort order, and icon size for specific folders, or reset a folder to your defaults. Changing view mode, sort, or icon size in a folder that hasn’t been customized updates your default across folders.
- **Browse search and duplicate results as List, Icons, or Gallery.** Switch presentations when viewing search results, Recents, or duplicate files without changing your folder view settings.
- **Search and reveal settings from the Command Palette (⌘K).** Type a setting name in the Command Palette to open the Settings window to that tab and highlight the control.
- **OpenDocument spreadsheet (`.ods`) previews.** Browse `.ods` workbooks across sheets with paging, column sorting, and cell search alongside CSV, SQLite, and Excel previews.
- **3MF 3D model previews.** Preview `.3mf` files with interactive rotation, zoom, part assemblies, dimensions, and triangle counts alongside `.stl` models.
- **LaTeX math in Markdown previews.** Render inline and display equations offline in Markdown previews.
- **Video storyboards, chapters, and audio waveforms.** Preview videos with a clickable storyboard strip, hover frames, chapter picker, and click-to-play/pause on the video surface, and preview audio files with a seekable waveform.
- **Capture location and media details in the Inspector.** See photo GPS coordinates (with options to copy coordinates or open in Maps), focal length, HDR status, chapter counts, and subtitle tracks.
- **Copy text from PDF previews.** Select and copy text directly inside Space and Inspector PDF previews.

## Fixed

- **Much lower background CPU usage and faster index catch-up.** Reworked background indexing to coalesce file bursts, defer noisy build/cache folders, read deep folder changes in parallel, and save on a 30-minute, sleep, and quit schedule. Eliminated redundant background folder-size walks on indexed folders while the index is loading or updating.
- **Cloud files stay offline during indexing.** Background content indexing skips dataless iCloud and cloud-synced placeholder files so they aren’t downloaded in the background.
- **Instant folder icons in the Inspector.** Replaced live Quick Look folder thumbnails in the Inspector with crisp folder icons to avoid background Quick Look activity when selecting folders.
- **Incremental loading and faster sorting in large folders.** Large folders show their first batch of items right away while the rest load, preserving selection and scroll position. Sorting large folders and refreshing folder sizes only update affected visible rows.
- **Responsive media scrubbing and resizable Inspector divider.** Fixed macOS 26 media preview issues where clicking or dragging the scrubber during playback could miss seeks and player controls prevented dragging the Inspector split-view divider narrower.
- **Readable path bar in narrow windows.** The location bar yields space to toolbar view controls while keeping parent folder breadcrumbs readable.
- **Shortcuts stay inside Quick Look.** Copy, Find, and selection shortcuts stay within the native Quick Look panel instead of acting on the file browser behind it.
