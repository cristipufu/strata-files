Strata 0.8.6 adds more file previews and fixes window restoration.

## New

- **Preview fonts before installing them.** Choose a font face and adjust the sample size.
- **Read Jupyter notebooks.** View formatted text, code cells and saved outputs together.
- **Preview design files.** View artwork from Krita, OpenRaster, Sketch and Procreate.
- **Explore GPS tracks.** See GPX, KML and GeoJSON routes on a map with elevation profiles.
- **More table previews.** Search JSON Lines, subtitles, HAR traces and Xcode string catalogs.
- **Inspect datasets and AI models.** View Parquet schemas, NumPy arrays, and SafeTensors or GGUF tensor details.
- **Check certificates and profiles.** See issuers, expiry dates and app signing details.
- **More details in the Inspector.** See richer information for books, fonts, design files and media.

## Fixed

- **Restore your window layout.** Keep tabs, dual panes, views, window size and position when reopening Strata.
- **Bring minimized windows back from the Dock.** Reuse the existing window instead of opening another.
- **Workspace choices take priority.** Selecting a saved workspace stops automatic restoration from opening an extra window.
- **Move between previews with the arrow keys.** Browse files without closing Quick Look.
- **Recognize Full Disk Access on macOS 27.** Stop asking for access that is already enabled.
- **Keep tags current.** Folder reloads now pick up newer tag changes.
