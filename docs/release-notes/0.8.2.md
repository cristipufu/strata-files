Strata 0.8.2 adds interactive table previews, Excel worksheets, STL models, richer Inspector details and clipboard visibility, and fixes slow or stale file previews.

## New

- **Interactive CSV and SQLite previews.** Browse large tables one page at a time, click column headers to sort numerically or alphabetically, and select cells or rectangles to copy their values.
- **Find on the current table page.** Search loaded cells across all displayed columns in CSV, SQLite and Excel previews. Return and Shift-Return move between matching cells. The search follows the current page and sort order.
- **Excel previews with multiple worksheets.** Open `.xlsx` files, choose a worksheet and page through its nonempty rows. Previews show saved cell values, cached formula results and common date formats, with the original worksheet row numbers.
- **Interactive STL model previews.** Preview ASCII and binary `.stl` files, drag to rotate, scroll to zoom and reset the view. Triangle counts and model dimensions help identify files before opening a slicer. Rendering works offline; dimensions use the file's own units because STL does not specify a unit of measurement.
- **Richer media details in the Inspector.** See photo capture dates, camera and lens information, exposure, aperture and ISO; video codec, frame rate and bit rate; and audio format and channel count. Details load for the inspected selection.
- **A visible file clipboard.** The footer shows how many files you copied or cut in Strata. Click it to inspect the paths or clear the clipboard. The contents popover follows the current theme, and the indicator clears when another app replaces the clipboard.

## Fixed

- **More responsive large table previews.** CSV previews read bounded pages instead of scanning a large part of the file just to show the first rows. SQLite queries run in separate sandboxed workers with memory and time limits, including limits on intermediate query results.
- **Preview cleanup and document errors.** Hiding the Inspector or closing a preview stops its background work. Results from an older selection cannot replace a newer preview, and native XML parsing errors are handled as preview failures.

Table previews are read-only. Sorting and Find apply to the loaded page, and Excel formulas are not recalculated. Very large worksheets or models and expensive SQLite queries may exceed preview limits and show a message instead of loading all their contents.
