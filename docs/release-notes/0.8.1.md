Strata 0.8.1 fixes a crash when previewing Mermaid diagrams in installed apps and improves the reliability of file previews, content search and document summaries.

## Fixed

- **Mermaid previews in installed apps.** Fixed a crash when opening Markdown containing Mermaid diagrams in the downloaded app. Missing diagram resources now leave the source visible instead of terminating Strata. ([#36](https://github.com/cristipufu/strata-files/issues/36))
- **More resilient Markdown and code previews.** Improved handling of text-rendering failures during layout, resizing, Find, diagram updates and line-number drawing. A failed renderer stops and shows a preview error.
- **Readable fallback for complex Markdown.** Documents that exceed formatting limits open as selectable, searchable source. Tables beyond the preview's row or column limits also show their source instead of silently dropping extra content. Large code fences keep their text without syntax highlighting when needed.
- **More reliable image reads.** Improved handling of image-decoding and metadata errors, with bounded preview images decoded before display.
- **Document indexing and summaries.** PDF and rich-text extraction handle read failures more safely. Cancelled PDF reads stop before processing further pages.

Very large images may be resized or skipped for text recognition to limit memory use. This can affect recognition of very small text.
