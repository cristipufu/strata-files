Strata 0.7.5 adds an optional address bar for each pane in Dual Pane mode, brings Catppuccin, Dracula and Tokyo Night to Color Themes, and fixes long path wrapping in the inspector.

## New

- **Address bar in each pane.** Enable Address bar in each pane in Settings ▸ General ▸ Browsing to give each side of a Dual Pane window its own full path bar. Click breadcrumbs or subfolder chevrons, see each pane’s Git branch pill, or click empty space and press ⌘L to type a path directly in the focused pane. The shared toolbar address bar hides automatically while two panes are open and returns in single-pane mode. Off by default.
- **Catppuccin, Dracula and Tokyo Night themes.** Three developer-favorite palettes join Settings ▸ Appearance ▸ Color theme, each with coordinated light and dark surfaces across file views, the sidebar, inspector and window chrome.

## Fixed

- **Long paths in the inspector wrap cleanly.** The Where path and container Mounts rows in the inspector now wrap multi-line paths without clipping or overlapping neighboring rows, while keeping labels aligned to the first baseline.
