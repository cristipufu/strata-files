# Strata Markdown preview samples

Select a file in Strata and press **Space** to preview it.

| No | File | What to look for |
| --: | :-- | :-- |
| 1 | [Mermaid diagrams](01-Mermaid-Diagrams.md) | Flowchart, sequence, class, state, and pie diagrams. |
| 2 | [Nested Mermaid](02-Nested-Mermaid.md) | Diagrams inside quotes and lists, plus nested Mermaid subgraphs. |
| 3 | [Markdown tables](03-Markdown-Tables.md) | Narrow IDs, long descriptions, alignment, and nested tables. |
| 4 | [Find in preview](04-Find-in-Preview.md) | Searchable prose, headings, tables, quotes, and code. |
| 5 | [Mixed document](05-Mixed-Document.md) | A small README combining diagrams, tables, tasks, and code. |
| 6 | [Fallbacks](06-Fallbacks.md) | An intentionally invalid diagram followed by a valid one. |

## Things to try

- Resize the preview window: long table text should wrap while small ID columns stay compact.
- Switch between light and dark appearance and check the diagrams.
- Type in the preview's **Find** field. Press **Return** for the next match and **Shift-Return** for the previous match.
- Search for `needle` or `resume` in the Find sample. Clear the field afterward.
- Close a preview while a diagram is loading, then open another file.
- Try opening the samples from List, Icons, Columns, and Gallery.

The diagram examples are self-contained and do not need an internet connection. The fallback sample is deliberately malformed; the other examples are intended to render normally.
